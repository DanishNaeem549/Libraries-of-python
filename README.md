# Python Libraries

A collection of Python examples and practice programs covering commonly used Python libraries. This repository is designed for learning, experimentation, and understanding how different Python libraries can be used in real-world projects.

## 📚 Libraries Covered

### NumPy

Used for numerical computing, arrays, mathematical operations, and scientific calculations.

```python
import numpy as np
```

### Pandas

Used for data manipulation, data analysis, DataFrames, and working with structured datasets.

```python
import pandas as pd
```

### Matplotlib

Used for creating charts, graphs, and data visualizations.

```python
import matplotlib.pyplot as plt
```

### Seaborn

Used for statistical data visualization and creating attractive analytical charts.

```python
import seaborn as sns
```

### Scikit-learn

Used for machine learning, preprocessing, model training, prediction, and evaluation.

```python
from sklearn.model_selection import train_test_split
```

### Requests

Used for sending HTTP requests and working with APIs.

```python
import requests
```

### BeautifulSoup

Used for parsing HTML and extracting information from web pages.

```python
from bs4 import BeautifulSoup
```

### Flask

A lightweight Python web framework used to build web applications and APIs.

```python
from flask import Flask
```

### FastAPI

A modern, high-performance Python framework for building APIs.

```python
from fastapi import FastAPI
```

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/your-username/python-libraries.git
```

Navigate into the project:

```bash
cd python-libraries
```

Create a virtual environment:

```bash
python -m venv venv
```

Activate the virtual environment on Windows:

```bash
venv\Scripts\activate
```

Activate it on macOS/Linux:

```bash
source venv/bin/activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```
